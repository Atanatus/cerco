# CERCO

First game project hosted on PROYECTOZ.

## Structure

- src/js: game logic
- src/css: game-specific styles
- assets/images: game artwork
- assets/audio: game-specific sounds
- data: game configuration

## Architecture

PROYECTOZ remains the shared platform.

CERCO is an independent game project.

Shared platform systems:
- Chat
- Player profile
- Navigation
- Global music player
- Celtic Flow visualizer

Game mechanics are not implemented by this setup.
